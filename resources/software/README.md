# BEATBox Software

BEATBox code and software documentation will be uploaded here as the software stack is finalized.

## Front-end GUI demo

A hardware-free Python mock-up is available in [`gui_demo`](./gui_demo/). It sketches the main control window and monitoring window using mock data, based on the current GUI reference screenshots.

Run it with:

```powershell
cd resources/software/gui_demo
python beatbox_gui_demo.py
```
