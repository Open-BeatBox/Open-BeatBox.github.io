What's included

Open-BEATBox is maintained as dedicated repositories — hardware, software, firmware, documentation and build guides — each carrying the open licence that suits its layer. The manual explains how they fit together.

Resource categories

Hardware

CAD, enclosure, eight KiCad circuit boards with manufacturing files, and mechanical designs (V2 and V3). Licensed CERN-OHL-S-2.0.

Firmware

Reserved for stand-alone firmware releases (GPL-3.0). The module firmware, written in MicroPython, is currently published in the Software repository.

Software

The PC control application, the MicroPython module firmware and a command-line test tool. Licensed AGPL-3.0.

Documentation

The Sphinx manual: how it works, build guide, hardware, software, firmware and CAN protocol, troubleshooting. Licensed CC-BY-4.0.

Build guides

Assembly, calibration, and validation steps for deployments. Held in the documentation repository.

Assets

Figures, renders, and diagrams for presentations and papers. Held in the documentation repository.
