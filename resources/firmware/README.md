# Firmware has moved

The module firmware (MicroPython, for the RP2040 boards) is currently published in the **[Open-BeatBox_Software](https://github.com/Open-BeatBox/Open-BeatBox_Software)** repository, in its `micropython/` folder (AGPL-3.0).

The **[Open-BeatBox_Firmware](https://github.com/Open-BeatBox/Open-BeatBox_Firmware)** repository (GPL-3.0) is reserved for stand-alone firmware releases and holds no firmware source yet.

How the firmware works and how to flash it: <https://open-beatbox.github.io/docs/manual/software/firmware/index.html>
