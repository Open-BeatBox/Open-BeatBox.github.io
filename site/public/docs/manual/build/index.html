Build your own Open-BEATBox¶

This is the starting point for building an Open-BEATBox. The guide brings the preparation notes, bill of materials, fabrication guidance, and step-by-step module tutorials into a single workflow.

Before you begin, read the safety notes and check that the bill of materials matches the hardware revision you intend to build. Prepare and inspect the fabricated parts before assembling the modules. Cards must be flashed before they are installed in a module; see Flashing the cards for the current status of those instructions.

Start the step-by-step guide¶

Module-by-module assembly

Follow the six Sphinx tutorials for the frame, bottle mount, feeder, light ring, photobeam gate, and screen. Each tutorial uses identifiers from the Master BOM and includes the available supporting media.

Open the modular Sphinx guide

Recommended build order¶

Complete every item in this preparation checklist before starting Step 1:

  • Read the safety notes before handling tools, inserts, soldering equipment, or plexiglass.

  • Download the Master BOM in XLSX or CSV format. Use the BOM validation checklist and revision and identifier conventions to resolve every incomplete field for the hardware revision being built.

  • Prepare the 3D-printed and laser-cut parts using the fabrication guide and the Open-BEATBox CAD and hardware files.

  • Flash all required cards before installing them in their modules.

Step 1 — Build the frame and enclosure¶

Follow the frame and enclosure tutorial to build the base, pillars, walls, and door. Stop before installing the additional modules or securing the top panel; return to that section in Step 7.

Step 2 — Build the water bottle mount¶

Follow the water bottle mount tutorial to build and prepare the mount for installation.

Step 3 — Build the feeder module¶

Follow the feeder module tutorial to assemble the housing, electronics, motor, and rotor.

Step 4 — Build the light ring module¶

Follow the light ring tutorial to assemble the housing, PCB, cap, and diffuser.

Step 5 — Build the photobeam gate¶

Follow the photobeam gate tutorial to install the IR boards, controller, cables, and covers.

Step 6 — Build the screen modules¶

Follow the screen module tutorial to build both touchscreen modules and install their controller PCBs, IR boards, and cabling.

Step 7 — Integrate and validate the system¶

Return to the final section of the enclosure tutorial to install the completed modules, position the photobeam gate, and secure the top panel. Complete the safety notes and every module checkpoint before use. Record deviations using the module and item identifier conventions, then report corrections through the assembly-tutorials issue tracker.
