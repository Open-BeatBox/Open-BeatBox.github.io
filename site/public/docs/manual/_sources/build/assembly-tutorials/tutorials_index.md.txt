# Beatbox Assembly Tutorials

Follow these guides in numerical order to build the enclosure and its sub-modules.

## Assembly sequence

| Step | Tutorial | What to complete |
|---:|---|---|
| **1** | [Frame and enclosure assembly](modules/mod-frm-assembly.md) | Build the base, pillars, walls, and door. Leave module installation and the top-panel closure until Steps 2–6 are complete. |
| **2** | [Water bottle mount](modules/mod-bmt-assembly.md) | Build and prepare the water bottle mount for attachment to the enclosure. |
| **3** | [Feeder module](modules/mod-fdr-aseembly.md) | Build the feeder housing, electronics, motor, and rotor. |
| **4** | [Light ring module](modules/mod-lgt.md) | Build the light ring housing, PCB, cap, and diffuser. |
| **5** | [Photobeam gate](modules/mod-pbg-assembly.md) | Build the photobeam gate, IR boards, controller, cabling, and covers. |
| **6** | [Screen module](modules/mod-scr-assembly.md) | Build both touchscreen housings, controller PCBs, IR boards, and cabling. |
| **7** | <a href="modules/mod-frm-assembly.html#install-the-additional-modules">Final enclosure integration</a> | Install the completed modules, position the photobeam gate, complete the final checks, and secure the top panel. |

Steps 1 and 7 use the same enclosure guide: Step 1 prepares the structure, and Step 7 completes the integration after all sub-modules are ready.

For parts and quantities, see the [bill of materials](BOM.csv).
