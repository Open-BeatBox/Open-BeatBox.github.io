## Before module assembly

Cards must be flashed before they are installed in a module. Start with {doc}`Flashing the cards <flashing-cards>`; detailed flashing instructions are being prepared.

## Core modules

- Base and wall frame.
- Door wall and door hardware.
- Feeder module.
- Screen module.
- Tunnel module.
- Ceiling / light module.
- IR barriers and nosepoke sensors.
- Raspberry Pi shield / master electronics.
