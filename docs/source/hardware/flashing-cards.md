# Flashing the cards

The cards used by BEATBox must be flashed **before they are installed in their modules**. Flashing them first keeps the storage media accessible and makes it possible to verify each card before the hardware is assembled.

```{admonition} Instructions in preparation
:class: note
Detailed card images, flashing tools, configuration settings, and verification steps will be added here soon.
```

Until those instructions are published, do not install an unflashed card in a module. Confirm the correct image and configuration with the BEATBox team before continuing the build.
