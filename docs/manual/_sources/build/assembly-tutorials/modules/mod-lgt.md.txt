# Light Ring Module Assembly Instructions

## Parts and tools

Complete reference in [module BOM](../BOM.csv).

| item_id | category | description | quantity |
|---|---|---|---:|
| `PRT-LGT-001` | 3D-printed part | light ring base | 1 |
| `PRT-LGT-002` | 3D-printed part | light ring cap | 1 |
| `PRT-LGT-003` | laser-cut part | light diffuser / cover | 1 |
| `PCB-LGT-001` | circuit board | light ring PCB | 1 |
| `FST-INS-M3-BRASS` | fastening hardware | M3 brass threaded insert for plastics | 7 |

## 1. Prepare the housing

### 1.1 Install the threaded inserts

1. Inspect the `PRT-LGT-001` light ring base and clear all insert holes of printing debris.
2. Place the base on a flat, solid surface.
3. Install the seven `FST-INS-M3-BRASS` M3 threaded inserts in the inner circunference of the `PRT-LGT-001`, keeping each insert straight.
4. Install the seven `FST-INS-M3-BRASS` M3 threaded inserts in the rectangular face of the `PRT-LGT-001`. Look at the video for reference. 
5. Press each insert fully into its seat.

## 2. Install the electronics

### 2.1 Install the light ring PCB

1. Orient the `PCB-LGT-001` light ring PCB correctly in the `PRT-LGT-001` base.
2. Verify that the rear connector remains accessible.
3. Secure the PCB with four `FST-M3X6` M3 × 6 mm screws.

> **Caution:** Do not overtighten the PCB fasteners.

## 3. Close the light ring

### 3.1 Install the cap

1. Orient the `PRT-LGT-002` light ring cap relative to the base.
2. Check that the cap aligns with the threaded inserts and rear connector opening.
3. Secure the cap with two `FST-M3X10` M3 × 10 mm screws.
4. Tighten until the cap is fully seated without deforming the printed parts.

## 4. Install the light diffuser

1. Position the `PRT-LGT-003` light diffuser over the LED ring.
2. Align it with the corresponding housing features.
3. Verify that it sits flat without contacting or stressing the LEDs.
4.  Secure the cap with `FST-M3X10`

**Checkpoint:** The diffuser is correctly seated and does not interfere with the PCB or LEDs.
