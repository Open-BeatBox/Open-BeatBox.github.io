Build Open-BEATBox module by module.

Hardware build path

  1. 1

    Check the Master BOM

    Download the CSV or XLSX, confirm the hardware revision, and resolve every row still marked for validation before ordering.

    Open BOM
  2. 2

    Prepare fabricated parts

    Download the available CAD and production files, then inspect every printed and laser-cut part before assembly.

    Open hardware files
  3. 3

    Assemble each module

    Follow the frame, bottle mount, feeder, light ring, photobeam gate, and screen tutorials. Each guide uses the item IDs from the Master BOM.

    Open tutorials
  4. 4

    Validate the complete build

    Complete the checks in the Sphinx build guide and record any discrepancy with its module ID, item ID, and hardware revision.

    Open build guide

Firmware

  1. 1

    Order and check the boards

    Order the circuit boards from the manufacturing files in the Hardware repository, preferably assembled.

    How to order
  2. 2

    Flash every module board

    Install MicroPython (drag one file onto a USB drive), then deploy the module program with one command. Do this before closing the board into its housing.

    Flashing guide
  3. 3

    Test with the command-line tool

    Type SCAN and check that every module answers; feed a pellet, show a pattern, switch the lights.

    First power-up
  4. 4

    Understand the firmware

    Architecture, deployment reference and the CAN message specification.

    Firmware reference

Software

  1. 1

    Install the PC application

    Install Python with conda, then the application. No programming is needed.

    Installation
  2. 2

    Run a training stage

    Choose a stage and enter the animal's details, connect to the box, choose a folder, start.

    Using the application
  3. 3

    Configure the experiment

    Patterns, sequences, thresholds and timings are set in a plain text file.

    Configuration
  4. 4

    Read your data

    Every session writes a trial log and an event log as CSV files.

    Data files

Open-BEATBox - Open — Behavioural and Autonomous operant Box

Open-BEATBox is an open-source, autonomous, customizable, and low-cost system for ecological behavioral data acquisition in home-cage environments.
